# Mangrove MRV — เบสไลน์และการติดตามต้นไม้

เว็บภาษาไทยสำหรับดูข้อมูลต้นไม้ในแปลงตัวอย่าง ตรวจสอบแหล่งที่มา และเตรียมติดตามผลวัดในปีถัดไป

- **เว็บสาธารณะ:** https://mrv-002-public.gon1122.chatgpt.site
- **พื้นที่บันทึกผลสำรวจ (ต้องมีสิทธิ์):** https://mangrove-mrv-baseline.gon1122.chatgpt.site
- **Source:** https://github.com/saratchai1/mrv-002

## สิ่งที่เปิดให้สาธารณะดูได้

ภาพรวมเบสไลน์ รายละเอียด 32 แปลง ทะเบียนข้อมูลการวัด 8,326 รายการ การค้นหา/กรอง ประเด็นคุณภาพข้อมูล และรายงานเบสไลน์พร้อมพิมพ์หรือบันทึก PDF ผ่านเบราว์เซอร์ ดาวน์โหลดข้อมูล CSV, JSON และ Excel ต้นฉบับได้จากหน้าเว็บ

หน้าเว็บสาธารณะเป็น static site ไม่ใช้ฐานข้อมูลผลสำรวจส่วนตัว ไม่อ่านแคชผลสำรวจหรือคิวออฟไลน์ และไม่มี API สำหรับแก้ไขข้อมูล ปุ่มบันทึกผลวัดเชื่อมไปยังพื้นที่สำรวจส่วนตัว ข้อมูลรอบสำรวจใหม่ รูปภาพ และรายงานร่างในพื้นที่นั้นจะไม่ปรากฏในเว็บสาธารณะโดยอัตโนมัติ

พื้นที่ส่วนตัวรองรับสร้างรอบสำรวจ บันทึกผลวัดซ้ำของต้นไม้เดิม แนบภาพ เก็บคิวเมื่อออฟไลน์ และตรึงรายงานรอบสำรวจ ส่วนการลงทะเบียนต้นไม้ใหม่ที่ยังไม่มีในเบสไลน์และการนำเข้าผลวัดทั้งชุดยังไม่ได้ทำ

## รันเว็บสาธารณะ

ใช้ Node.js 22.13 ขึ้นไป (ตรวจสอบงานนี้ด้วย Node.js 24):

```sh
npm ci
npm run build
npm start
```

เปิด `http://localhost:4173` หรือใช้ `npm run dev` เพื่อ build และเปิด preview ในคำสั่งเดียว หลังแก้ไขโค้ดให้เริ่มคำสั่งนี้ใหม่

```sh
npm run typecheck
npm test
npm run test:public
```

`test:public` ต้องรันหลัง `npm run build` เพราะตรวจไฟล์ที่เผยแพร่จริง รวมจำนวนแถว CSV ความตรงกันของ JSON และ checksum ของ Excel ต้นฉบับ

ผลลัพธ์อยู่ใน `dist/` และรองรับ static hosting รวมถึง GitHub Pages ที่อยู่ใน subpath เช่น `/mrv-002/` โดยใช้ลิงก์แบบ relative เว็บที่ลิงก์ไว้ข้างต้นเผยแพร่ผ่าน ChatGPT Sites; repository นี้ยังไม่ได้เปิด GitHub Pages อัตโนมัติ

## ที่มาและข้อจำกัดของข้อมูล

ข้อมูลมาจาก `MOC2_VSD-25-06-24 3(1).xlsx` โดยเก็บค่าต้นฉบับและตำแหน่งแถวสำหรับตรวจสอบย้อนกลับ SHA-256:

```text
6f95f24e7632cc5901a8ea36bc9ecad9807d18ba42a42364df7876439e82b89a
```

- มี 8,326 รายการการวัด แต่ผลรวมช่องจำนวนต้นในไฟล์เป็น 6,738 จึงแสดงแยกกัน
- มีเลขต้นซ้ำ 213 กลุ่ม (429 รายการ) และเลขต้นว่าง 1 รายการ ต้องตรวจหน้างานก่อนนำไปจับคู่ผลวัดซ้ำ
- ปีอ้างอิงในแบบจำลองคือ พ.ศ. 2567; วันที่ลงสำรวจจริงยังไม่ยืนยัน ช่องที่ไม่ทราบเว้นว่าง
- ค่าคาดการณ์ พ.ศ. 2568–2577 เป็นผลจากสมมติฐานในไฟล์ ไม่ใช่ผลวัดใหม่
- ค่า stock และสูตรในหน้าสาธารณะเป็นการถอดและตรวจสอบไฟล์ต้นทาง ไม่ใช่การรับรองคาร์บอนเครดิต
- รายการ TRUL2 ที่กำกวมเรื่อง DBH/เส้นรอบวงคงค่าต้นทางและติดธงไว้ ไม่ใช้คำนวณการเปลี่ยนแปลงแบบจับคู่จนกว่าจะยืนยัน

ดูรายละเอียด ตัวเลขกระทบยอด และสิ่งที่ยังต้องยืนยันใน [ผลวิเคราะห์เบสไลน์](docs/baseline-analysis.md)

## พัฒนา/ติดตั้งพื้นที่สำรวจส่วนตัว

โค้ด backend อยู่ใน repository เพื่อพัฒนาต่อ แต่การรันต้องมี deployment configuration และ Cloudflare D1/R2 ของโครงการนั้นเอง ไฟล์ `.openai/hosting.json` ของพื้นที่เดิม รวมถึงฐานข้อมูลจริง รูปภาพ และข้อมูลคิวออฟไลน์ ไม่ได้รวมอยู่ใน repository นี้

คำสั่งสำหรับ backend คือ `npm run dev:private`, `npm run build:private` และ `npm run start:private` หลังตั้งค่าระบบที่รองรับแล้ว ตรวจ schema ใน `db/` และ `drizzle/` ก่อนติดตั้ง GitHub Pages รัน backend นี้ไม่ได้

การตั้งสิทธิ์ของพื้นที่สำรวจเดิมเป็น owner-only และเป็นส่วนหนึ่งของการจำกัดการเขียนข้อมูล ก่อนนำ backend ไปเปิดให้คนทั่วไปต้องออกแบบสิทธิ์ผู้บันทึก/ผู้ตรวจทานเพิ่มเติม
